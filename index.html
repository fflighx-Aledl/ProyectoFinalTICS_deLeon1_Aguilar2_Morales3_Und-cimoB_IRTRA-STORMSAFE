01 — EL PROYECTO

Seguridad ante un clima impredecible

StormSafe nace como una propuesta de automatización enfocada en la seguridad operacional de las atracciones.

⛈️

La problemática

Durante la operación de un parque de atracciones pueden presentarse condiciones meteorológicas adversas, como lluvias intensas y tormentas eléctricas.

Determinadas atracciones podrían requerir una suspensión preventiva ante estas condiciones para reducir riesgos para visitantes y trabajadores.

🛡️

Nuestra solución

IRTRA StormSafe propone un sistema electrónico autónomo capaz de recibir una señal de alerta meteorológica y activar un protocolo preventivo.

El prototipo utiliza indicadores visuales y sonoros para representar los estados de operación, precaución y suspensión de una atracción.
